# Job Leads — Tool-Vendor Company Cross-Reference

Tracks open roles found at companies from `Target Companies.md` (Databricks/Tableau/Snowflake
customers), matched against Fran's target titles from `Context/Career Notes.md`
(Analytics Engineer, Solutions Engineer, BI Developer, Forward Deployed Engineer, Data
Solutions Engineer, etc.). Searched via web search across each company's career page +
LinkedIn/job boards.

Each run appends a dated section. Compare against the previous run to spot **new** postings
— that's the useful signal, since most of these companies always have *some* open req.

## Notes on reliability
- Web search results are a snapshot and miss postings not well-indexed — the career-page
  category links above are more reliable for a manual check than trusting search absence
  as "no jobs."
- Several "matches" are inferred from search-engine summaries, not confirmed live postings —
  verify before treating as current (job pages get pulled/filled quickly).
