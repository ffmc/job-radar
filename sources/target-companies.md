# Target Companies — Tool Vendor Customers

Companies known to use tools in Fran's stack (Databricks, Tableau, Snowflake). Rationale:
if a company already runs these tools, roles referencing them are a stronger keyword/skills
match — worth prioritizing in the search.

Sourced from vendor customer-story pages via Claude in Chrome (Sept 2026), paging through
each directory. These directories are still much larger than what's captured here
(Databricks: 946 customer stories / 20,000+ customers total, Tableau: 86,000+, Snowflake:
~380 case studies across 32 pages) — what's below covers roughly the first 100-190 entries
per vendor, not the full list. Browse further for more:
- Databricks: https://www.databricks.com/customers (page through `?page=N`)
- Tableau: https://www.tableau.com/solutions/customers (click "Load More")
- Snowflake: https://www.snowflake.com/en/customers/all-customers/ (`?offset=N`, 12/page)
